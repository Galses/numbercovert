# C++ Number Converter

Плагин для **Visual Studio Code** (TypeScript) для работы с числовыми литералами в C++.

## Описание

Плагин помогает работать с числами в разных системах счисления прямо в редакторе:

1. **Подсказка при наведении.** Если навести мышь на число в C/C++ коде, появится таблица с этим числом в двоичной, восьмеричной, десятичной и шестнадцатеричной системах.
2. **Перевод по горячей клавише.** Поставьте курсор на число и нажмите сочетание клавиш, число в коде заменится на запись в выбранной системе счисления.

### Горячие клавиши

| Клавиши | Действие | Пример (из `255`) |
|---|---|---|
| `Ctrl+Alt+H` | в шестнадцатеричную | `0xFF` |
| `Ctrl+Alt+N` | в десятичную | `255` |
| `Ctrl+Alt+O` | в восьмеричную | `0377` |
| `Ctrl+Alt+B` | в двоичную | `0b11111111` |

Те же команды доступны через палитру команд (`Ctrl+Shift+P`), если ввести «Число ».

### Поддерживаемые записи чисел

- десятичные: `255`
- шестнадцатеричные: `0xFF`, `0XFF`
- двоичные: `0b1010`
- восьмеричные: `0755`
- разделители разрядов: `1'000'000`
- большие значения
- суффиксы `u`, `l`, `ull` не затрагиваются

### Ограничения

- Отрицательные числа: знак минус считается отдельным оператором, число `-5` обрабатывается как `5`.
- Дробные (`3.14`) и экспоненциальные (`1e5`) записи не поддерживаются.
- Работает только в файлах C++.
